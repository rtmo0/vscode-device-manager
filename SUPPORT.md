# Support

Use the repository issue tracker to report bugs or request features. Include your OS, VS Code version, Mobile Device Manager version, `adb version`, the device model and Android version, how the device is connected (pairing code, `adb tcpip`, USB) and steps to reproduce the problem. **Mobile Device Manager: Show Output** shows the adb commands that were run (set the log level to Trace for all of them). Remove IP addresses, serial numbers and private file names from logs before sharing them.
